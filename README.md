# Book Management App - React Native

This is a **Book Management App** developed using **React Native**. The application allows users to manage a collection of books by adding, viewing, and updating information about the books. It also supports features like uploading a book cover image and navigating through different pages.

## Features

- **Add a new book**: Users can add a book by entering its title, author, published date, ISBN, category, and upload a cover image.
- **Book list view**: Displays the list of all added books with essential details.
- **Edit book information**: Users can edit the details of an existing book.
- **Delete a book**: Allows users to remove a book from the list.
- **Image Picker**: Enables users to select a cover image from the device’s gallery.
- **Navigation**: Smooth navigation between different screens such as the home page, add book page, and admin page.
